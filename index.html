How to Use

  1. Login to the dashboard using your credentials.
  2. On the Reports Overview page, click the "New Scan" button.
  3. Upload your .json report file generated by Droid-LLM-Hunter.
  4. Wait for the analysis to process and view the results in the interactive dashboard.

Frequently Asked Questions

Why is my upload failing?

Ensure your file is a valid JSON file generated by the tool. Check if the file contains app_summary and results fields.

How do I delete a report?

Go to the Reports Overview (Home) page and click the "Delete" button next to the report you wish to remove.
